# 📅 Generador d'Horaris Escolars (Web App Frontend)

Aquesta carpeta conté el codi font en **React 19 + Vite 8 + Tailwind CSS v4** del **Generador d'Horaris Escolars**.

---

## 🟢 PER A L'USUARI FINAL (Sense instal·lacions)

Per utilitzar l'aplicació directament al navegador a través de **GitHub Pages**:
👉 **[Consulta la Guia d'Usuari al README Principal](../README.md#-opció-1-accés-web-directe-recomanat)**

---

## 🛠️ PER A DESENVOLUPADORS (Comandes de Terminal)

```bash
# Instal·lar dependències
npm install

# Servidor local de desenvolupament
npm run dev

# Compilar per a producció (GitHub Pages)
npm run build
```
